# CLI & Configuration

> CLI, config, flags và compatibility.

# 26. CLI và configuration change

Với CLI change, verify:

- flag naming hiện có;
- default;
- help text;
- exit code;
- stderr/stdout convention;
- backward compatibility;
- shell-sensitive quoting khi liên quan.

Với config change, verify:

- schema hoặc parser thật;
- environment variable naming;
- precedence giữa các config source;
- default value;
- missing-value behavior;
- khác biệt production và development.

Không phát minh configuration key.
